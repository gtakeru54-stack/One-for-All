# One-for-All

One-for-All は、予定を立てて、実際にやったことを記録し、振り返るための学習管理アプリです。

主な機能
- 日ごとの予定登録
- カレンダー表示
- 土曜・日曜・祝日を色分けして見やすく表示
- 予定と実績を比較して達成率を確認
- 今日の振り返りメッセージを表示
- ブラウザの localStorage に保存して、再読み込みしてもデータを維持

使い方
1. カレンダーの日付を選ぶ
2. 予定を登録する
3. 実際にやった内容を記録する
4. 予定と実績の差を見て、次の行動に活かす

このアプリは、勉強や学習の継続を支えるためのシンプルな管理ツールとして設計しています。
