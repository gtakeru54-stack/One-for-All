カレンダー＆タスク アプリ

■ 起動方法
1. calendar_app フォルダをパソコンに展開します。
2. index.html を Chrome、Edge、Safari などのブラウザで開きます。
3. 「予定を追加」または日付をタップして予定を登録します。

■ ファイル構成
calendar_app/
├─ index.html
├─ css/
│  └─ style.css
└─ js/
   └─ app.js

■ 実装済み
・月表示、前月／翌月、今日に戻る
・日付選択、予定の追加／編集／削除
・予定名、日付、開始・終了時刻、色、詳細
・予定時刻のブラウザ通知（ページを開いていて通知許可がある場合）
・タスクの追加／編集／削除／完了チェック／期限
・localStorage への保存
・JSON形式でのバックアップ書き出し／読み込み
・スマホ向けレイアウト

■ 制限事項
・データはそのブラウザ・端末内に保存されます。別端末とは自動同期されません。
・ブラウザの通知は、ページが開いている間に限った簡易実装です。ページを閉じている間の通知は保証されません。
・ブラウザやプライベートモードの設定によっては保存データが消えることがあります。定期的に「データを書き出す」でバックアップしてください。
・iPhoneなどでは、ブラウザ通知やローカルファイルの扱いに制限がある場合があります。

■ 既存プロジェクトに組み込む場合
新規アプリとして動く構成です。既存アプリへ組み込む場合は、既存のフレームワークやフォルダ構成に合わせた調整が必要です。
